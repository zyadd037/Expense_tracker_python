
# Expense Tracker

#Idea 
A Python-based expense tracker for managing daily expenses, storing data in JSON, and generating monthly summaries.

## Features
- Add new expenses with amount, category, and date.
- Display all recorded expenses.
- Calculate monthly expense summaries.
- Organize expenses by category.
- Save and load expense data using JSON files.
- Simple menu-driven interface.

## Technologies Used
- Python
- JSON
- datetime module
- expense-tracker
- file-handling
   

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python expense_tracker.py
```

5. Follow the instructions displayed in the terminal.

## Project Goals
This project demonstrates basic Python programming concepts, including:
- Functions and loops.
- Lists and dictionaries.
- File handling.
- JSON data storage.
- Date handling and expense calculations.
